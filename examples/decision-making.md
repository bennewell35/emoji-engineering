# Decision-Making

Tiny diagrams for tradeoffs, gates, option maps, confidence, and yes/no paths.

## Decision Gate

```text
📊
⬇️
🧠
⬇️
✅ / ❌
```

Use for evidence, judgment, and go/no-go.

## Option Map

```text
        🅰️
       ↗️
❓ → 🅱️
       ↘️
        🅾️
```

Use for showing multiple paths from one question.

## Confidence Ladder

```text
⬜ guess
🟨 signal
🟩 proof
```

Use for separating opinions from evidence.

## Tradeoff Scale

```text
⚡ speed  🟨🟨🟨🟨⬜
🛡️ safety 🟩🟩🟩⬜⬜
💸 cost   🟩🟩⬜⬜⬜
```

Use for comparing product or engineering tradeoffs.

## Stop Or Ship

```text
🧪
⬇️
✅ yes → 🚀
❌ no  → 🛠️
```

Use for a clear validation gate.
