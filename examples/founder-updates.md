# Founder Updates

Tiny diagrams for build-in-public posts, weekly updates, pivots, launches, and traction notes.

## Build In Public

```text
💡 idea
⬇️
🛠️ built
⬇️
📸 shared
⬇️
💬 feedback
⬇️
🚀 shipped
```

Use for a concise public progress update.

## Weekly Builder Update

```text
🛠️ shipped
🧪 tested
👀 learned
🎯 next
```

Use for weekly founder or indie-hacker updates.

## Pivot Map

```text
🟥 old bet
⬇️
👂 user signal
⬇️
🟨 new angle
⬇️
🟩 sharper bet
```

Use when explaining why a product direction changed.

## Traction Snapshot

```text
👀👀👀👀👀
⬇️
👤👤👤
⬇️
💳
⬇️
❤️
```

Use for awareness, users, customers, and retention.

## Launch Note

```text

```

Use for a simple "we built, checked, announced, shipped" update.
