# Pixel Art Grid Template

Use this for tiny banners, flags, maps, mascots, launch art, and contribution-style grids.

```text
⬜⬜⬜⬜⬜
⬜🟦🟦🟦⬜
⬜🟦⭐🟦⬜
⬜🟦🟦🟦⬜
⬜⬜⬜⬜⬜
```

Tips:

- Keep grids small.
- Use square emoji when shape matters.
- Test the grid in the place where you plan to post it.
- Avoid copying existing artwork directly.
