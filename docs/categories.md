# Categories

Emoji Engineering is organized by reusable communication contexts.

## AI Agents

Pipelines, context windows, tool use, review gates, and human-in-the-loop workflows.

## Product Workflows

Discovery, feedback loops, feature flags, product bets, and user-signal diagrams.

## Engineering Systems

CI, incidents, data pipelines, service health, deploy flow, and reliability updates.

## Fitness / Health Data

Recovery, training load, adherence, readiness, and health-metric snapshots.

## Bookmark Maxxing

Saved links, source mining, digest creation, and turning repeated signal into reusable output.

## GitHub / Open Source

Issues, pull requests, reviews, contribution art, releases, and maintainer workflows.

## Launch Checklists

Launch gates, founder updates, public build logs, and post-launch follow-through.

## Flags / Pixel Art

Original grids, status flags, tiny banners, progress bars, and playful pixel-art patterns.
