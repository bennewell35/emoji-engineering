# Style Guide

Emoji Engineering should stay simple, useful, and easy to remix.

## Voice

Playful but builder-serious.

Use short explanations. The diagram should carry most of the meaning.

## Diagram Shape

Prefer:

- Vertical flows for processes
- Small grids for status or pixel art
- Short checklists for launch or review gates
- Arrows only when they clarify direction

Avoid:

- Huge emoji murals
- Jokes that are not useful
- Diagrams that require long explanations
- Direct copies of viral posts or branded assets

## Copy-Paste Quality

Every diagram should work as plain text.

Before adding a diagram, paste it into:

- A markdown preview
- A plain text editor
- A chat box or social composer when possible

If the shape breaks in common places, simplify it.

## Attribution

Credit direct inspiration. Do not copy the original work directly.

The project origin can be described as:

```text
Inspired by Guillermo Rauch’s emoji flag post.
```
