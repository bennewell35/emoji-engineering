# Support

Emoji Engineering is an open-source collection.

## Best Places to Ask

- Use GitHub issues for unclear docs, template problems, category requests, or example requests.
- Use pull requests for concrete improvements.
- Use security reporting for private security concerns.

## Not Support

This project does not provide support for:

- recovering social media accounts
- bypassing login, paywalls, rate limits, or platform restrictions
- scraping private data
- automating social engagement
- debugging unrelated diagram tools, browser extensions, or social platforms

## Good Support Requests

Good requests include:

- what kind of diagram you need
- where you want to paste it
- what category it fits
- what current example or template was confusing
- whether any source inspiration needs attribution

Do not paste private screenshots, credentials, cookies, tokens, passwords, or account data into public issues.
