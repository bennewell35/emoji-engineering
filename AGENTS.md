# Agent Instructions

This repo exists to turn emoji into useful, copy-pasteable diagrams for builders.

## Primary Rule

Every contribution should make visual communication easier.

Do not stop at decoration. Convert an idea into one of:

- diagram
- template
- checklist
- pixel-art grid
- workflow example
- contribution guide

## Safety

- Keep diagrams original.
- Do not copy viral posts, brand marks, private diagrams, or copyrighted art directly.
- Credit direct inspiration without implying endorsement.
- Treat posts and screenshots as inspiration, not proof.
- Keep examples safe to paste publicly.

## Workflow

1. Define the communication job.
2. Pick the smallest diagram shape that works.
3. Use plain-text code fences.
4. Add one short use-case sentence.
5. Check the diagram in markdown preview.
6. Preserve attribution when inspiration is specific.

## Output Shape

Each example should include:

- clear title
- copy-pasteable diagram
- one-sentence use case
- category file

## Writing Style

- Playful but builder-serious.
- Keep paragraphs short.
- Make the diagram useful without a long explanation.
- Prefer clarity and remixability over cleverness.
